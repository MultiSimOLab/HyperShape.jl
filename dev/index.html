HyperShape.jl

HyperShape is a library for shape and topology optimisation of nonlinear multiphysics problems: finite-strain hyperelasticity, electro-, magneto- and thermo-mechanics. It is built on HyperFEM, within the Gridap ecosystem.

Status

Phase 0 is implemented and validated: density methods for linear problems (Helmholtz filter, tanh projection, optimality criteria and SiMPL, consistency checks, continuation, checkpoints, fast output), reproducing top88 and the SiMPL paper (see Validation). The reaction–diffusion method (level set through an interface map, or density) is implemented. Nonlinear and multiphysics problems and level-set methods come in the next phases (Roadmap). The package is not registered yet.

Principles

  • HyperFEM is used as a black box. The forward and adjoint problems are HyperFEM computational models that the user builds with their own weak forms.
  • The user configures every solver. HyperShape chooses none: not for the state, the adjoint, the filter or the internal solves of the methods. Every default of the loop can be replaced from the script.
  • Analytical derivatives. No automatic differentiation; every sensitivity is verified with a Taylor test (check_consistency).
  • One abstraction for several methods. Density, reaction–diffusion and level set are meant to share variables, states, functionals and the optimisation loop (density and reaction–diffusion methods are implemented).
