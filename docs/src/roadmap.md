# Roadmap

| Phase | Content |
|---|---|
| 0. Foundations | Variables, operators, functionals, common loop, Helmholtz filter, optimality criteria and SiMPL, consistency checks. Validation on linear benchmarks |
| 1. Nonlinear and multiphysics SIMP | Constitutive wrappers, robustness of the forward solve, staggered models, robust projection |
| 2. Reaction–diffusion and level set | Reaction–diffusion step, level-set evolution, augmented Lagrangian |
| 3. Real geometries | STL/CAD to signed distance, non-design regions, Cartesian background meshes, multigrid |
| 4. Octree meshes and MPI | Adaptive octree meshes, distributed optimisers |
| 5. Body-fitted remeshing | Level set with explicit interfaces on remeshed unstructured meshes |
| 6. GPU | Matrix-free operators and multigrid on GPU |
